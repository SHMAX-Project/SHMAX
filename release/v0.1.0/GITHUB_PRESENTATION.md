## Announcement draft

SHMAX v0.1.0 — шлюз между MAX и Telegram для собственного сервера.
Обмен сообщениями и вложениями в обе стороны, маршрутизация по темам,

SHMAX v0.1.0 is a self-hosted gateway between MAX and Telegram with

a web interface, backups and updates with rollback.
