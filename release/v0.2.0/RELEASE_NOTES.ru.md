# SHMAX v0.2.0

- Несколько Telegram-групп: отдельные привязки чатов MAX и права отправки для каждой группы.
- Админские форум-группы: автоматические темы для новых чатов MAX, просмотр обеих сторон переписки.
- Настраиваемые подписи: исходный чат и фактический отправитель.
- Независимый маршрут MAX: напрямую, HTTP, SOCKS5 или Xray; отдельный от Telegram.
- Дашборд: графики CPU, памяти и диска, группы и привязки, состояние сетевых маршрутов.
- Мастер первичной настройки из десяти шагов, проверенный на компьютере и телефоне.
- Импорт обычных и зашифрованных резервных копий v0.1.0–v0.1.3 через проверку и предварительный просмотр.

Служебная часть резервного копирования обновляется вместе с версией и миграциями приложения; прежние файлы сохраняются для отката.

## Обновление и ограничения

Миграция сохраняет группы, привязки, подписи, сессии и очередь; прежние разрешения переносятся только в прежнюю активную группу. Старая очередь MAX получает ключи с учётом группы для защиты от повторной доставки. Старые незавершённые задания Telegram без идентификатора отправителя требуют ручной проверки: их права нельзя надёжно восстановить. Перенос резервной копии на другой сервер изолирует незавершённую очередь, чтобы избежать повторной отправки.

Перед обновлением нужна холодная резервная копия на исходном сервере. Возврат на старую схему выполняется восстановлением проверенной копии, а не обратной миграцией с потерей групп. Старые снимки updater без манифеста приложения остаются отдельным способом аварийного восстановления.

Один аккаунт MAX. Для подключения новых групп нужен форум с темами. Видимость сообщений определяется членством в Telegram-группе. История графиков хранится в памяти до часа и сбрасывается при перезапуске. Новые сетевые маршруты проверены локально, без отправки реальных сообщений.

Обновление существующего сервера проверено с подписанным архивом, холодной копией и контролем восстановления MAX/Telegram.

## Проверки и безопасность

На существующей Debian 13 amd64 проверены подписанное обновление, миграция, hostd, сохранность настроек/очереди, перезапуск компонентов и полный ребут с автозапуском. Пройдены регрессии альбомов/медиа/доставки по группам, desktop/mobile настройка и макеты, импорт копий всех четырёх предыдущих выпусков. [Доказательства и ограничения](VALIDATION.md).

Проверяйте `SHA256SUMS` и `SHA256SUMS.sig` существующим доверенным публичным ключом. Приватные ключи и серверные копии не входят в выпуск. Опубликованные v0.1.0–v0.1.3 не изменяются.
