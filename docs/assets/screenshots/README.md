# Скриншоты / Screenshots

## v0.2.1

Новые снимки показывают интерфейс SHMAX v0.2.1 из подписанного архива. Замеры CPU, памяти и диска, статусы подключений и группы заданы демонстрационными данными. Журнал показывает пять тестовых событий из локальной базы. Снимки сделаны в Chromium с шириной 1440 и 375 CSS-пикселей. На мобильных снимках плотность пикселей 2×.

These screenshots show the SHMAX v0.2.1 interface from the signed package. Resource measurements, connection statuses and groups use demonstration fixtures, and the journal displays five fixture events from a local database. Chromium viewports were 1440 and 375 CSS pixels, with mobile captures at 2× density. No production accounts, messages or credentials appear in the screenshots.
