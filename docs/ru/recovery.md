# Восстановление

## Приоритет восстановления

1. Данные (`/var/lib/shmax`) — главная ценность.
2. Возможность войти в UI.
3. Последняя рабочая версия приложения.

## Сценарий: обновление не удалось (автооткат сработал)
Проверьте результат автоматического отката: при успехе предыдущая версия
поднята и проверена. Если откат тоже не удался, сохраните данные, соберите
диагностику и следуйте выданным инструкциям восстановления.
Изучите `docker logs`, попробуйте обновиться позже.

## Сценарий: контейнер после ребута не публикует порт
`cd /opt/shmax && docker compose up -d --force-recreate`, затем
`docker port shmax-web-1` — публикация должна появиться
(boot-юнит делает это автоматически).

## Сценарий: приложение сломано, данные целы
`bash /opt/shmax/install.sh --mode repair` — восстановит деплой,
данные сохранятся.

## Сценарий: нужно откатить конфигурацию
Восстановите копию: см. restore.md (safety-копии создаются
автоматически перед restore и обновлением).

## Крайний случай: полный снос
`install.sh --mode uninstall` — приложение сносится, данные
остаются. `--purge` — УДАЛЯЕТ `/var/lib/shmax` безвозвратно.
Не используйте purge как «лечение».
