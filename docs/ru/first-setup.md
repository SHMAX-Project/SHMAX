# Первичная настройка v0.2.0 — 10 шагов

После создания владельца выберите **Начать настройку**, **Восстановить из
резервной копии** или **Пропустить настройку**. Старые исправные настройки при
обновлении сохраняются: проходить мастер заново не требуется.

1. **Администратор.** Создайте локального владельца SHMAX по одноразовой ссылке
   и сохраните пароль. Это отдельная учётная запись, не MAX и не Telegram.
2. **Сеть MAX.** Оставьте прямое подключение либо настройте прокси/Xray.
   Сохраните выбор и проверьте соединение. Телефон пока не нужен.
   [Подробно о сети MAX](max-network.md).
3. **MAX аккаунт.** Введите телефон, получите и введите код; при запросе —
   пароль 2FA. Не запрашивайте коды подряд. Если MAX требует сначала включить
   2FA, сделайте это в официальном приложении MAX. Дождитесь подтверждения входа.
4. **Сеть Telegram.** Отдельно выберите Direct, SOCKS5, HTTP либо Xray.
   Для подписки загрузите узлы, выберите нужный и примените. Проверьте сеть.
   Выбор MAX не меняется.
5. **Telegram бот.** Создайте бота через @BotFather `/newbot`, вставьте токен
   и нажмите **Проверить и сохранить**. Проверьте `/setprivacy → Disable`.
   Пустое поле не перезаписывает сохранённый токен.
6. **Telegram группа.** Создайте закрытую группу, включите **Темы**, добавьте
   бота и выдайте права отправки и управления темами. Получите одноразовый код
   в SHMAX, отправьте `/shmax_connect КОД` в General и дождитесь подтверждения
   в мастере. Код выдаётся только при работающем слушателе бота.
7. **MAX чаты.** Выберите чаты и создайте привязки: каждый чат получает свою тему.
   Дополнительные группы, существующие темы и [админский обзор](multi-group.md)
   настраиваются после мастера в разделе Telegram → Настройки группы.
8. **Пользователи.** Одобрите нужных отправителей для первой группы. Новые
   участники и Telegram-администраторы не получают право отправки автоматически.
   Необязательное обнаружение участников через API ID/API Hash бота можно
   настроить позже; без него мост тоже работает.
9. **Проверка.** Запустите проверку. Если есть ошибка, перейдите к указанному
   компоненту, исправьте настройку и повторите. Успешный `getMe` не подтверждает
   получение обычных сообщений группы: проверьте права и живую доставку.
10. **Готово.** Завершите настройку и откройте [главную](dashboard.md).
    Проверьте сообщение и вложения из MAX, затем ответ Telegram → MAX.

## Вернуться, выйти или продолжить

Назад возвращает к предыдущему шагу. Блок SHMAX и ссылка «На главную» позволяют
выйти из мастера. Несохранённые изменения требуют подтверждения; выход не
удаляет настройки и не отменяет уже начатую авторизацию MAX. При запросе
кода/пароля дождитесь результата — не запускайте параллельный вход.

Пропуск записывает только отказ от продолжения мастера, а не успешную готовность.
Не настроенные компоненты останутся не настроенными. На главной есть
**Продолжить первоначальную настройку**. Создавать владельца повторно не нужно.

После настройки меняйте компоненты по отдельности: MAX → Настройки MAX / Сеть
MAX; Telegram → Настройки бота / Сеть / Группы; Пользователи → выбранная группа.
Истёкшая сессия или ошибка сети показывается в соответствующем разделе и не
сбрасывает всю конфигурацию.

## Если уже есть бекап

Выберите [восстановление](restore.md) сразу после создания нового владельца.
Переносимая v2 и старые локальные v1 проверяются до начала замены данных.
Для незашифрованной старой копии оставьте пароль пустым; для зашифрованной
используйте её исходный пароль. Остановите старый SHMAX перед запуском переноса.
Два экземпляра не должны использовать один аккаунт/бот одновременно.
