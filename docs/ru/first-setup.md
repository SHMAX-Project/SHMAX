# Мастер настройки — ровно 9 шагов

После обязательного создания владельца выберите «Начать настройку» для шагов 2–9,
[«Восстановить из резервной копии»](restore.md) для переноса готового SHMAX
или «Пропустить настройку», чтобы открыть главную и настроить компоненты позже.
Проверенный portable v2 восстанавливает конфигурацию и открывает dashboard
после повторного входа новым владельцем. Девять шагов свежей настройки сохраняются.

Канонический порядок:

1. **Администратор** — локальный админ SHMAX (ссылка настройки
   одноразовая; сохраните пароль).
2. **MAX** — телефон, привязанный к MAX. SMS может идти долго — не
   спамьте «Отправить снова». Если MAX пишет «Требуется 2FA» —
   сначала включите 2FA в официальном приложении MAX. После SMS
   может быть запрошен пароль 2FA.
3. **Telegram сеть** — Direct / SOCKS5 / HTTP / Xray-подписка
   (URL → «Получить подписку» → выбрать ноду → «Проверить
   соединение» → «Telegram доступен»).
4. **Telegram бот** — @BotFather → /newbot → токен в SHMAX →
   /setprivacy → Disable Privacy Mode.
5. **Telegram группа** — создать группу, добавить бота, включить
   «Темы», сделать бота админом (отправка сообщений + управление
   темами), «Получить одноразовый код», отправить в General:
   `/shmax_connect <КОД>`. Код выпускается только при живом
   слушателе бота (pair-code проверяет готовность listener'а).
6. **MAX чаты** — выбрать чаты; каждый станет отдельной темой.
7. **Пользователи** — одобрить доверенных; остальные не смогут
   писать в MAX.
8. **Проверка** — MAX-сессия, сеть, бот, права группы, маршруты,
   пользователи, очередь.
9. **Готово** — конфигурацию можно менять позже; данные остаются
   в `/var/lib/shmax`, приложение может заменяться при обновлении.

Встроенные подсказки мастера и страницы «Инструкция» используют общий
`frontend/src/help.tsx`; документация поддерживается согласованно с ними.

MAX подключается напрямую; выбранная сеть применяется только к Telegram.
На шаге «Пользователи» доступна необязательная [синхронизация участников](telegram-group.md#автоматическое-обнаружение-участников):
с API ID/API Hash она импортирует и молчавших участников от имени существующего
бота, без userbot. Настройки вводятся на странице Telegram; это не десятый шаг.
Без них мост работает, пользователи обнаруживаются по `chat_member` и видимым
сообщениям. Новые участники не одобрены; Telegram admin не даёт SHMAX admin.

Предупреждение Privacy Mode при проверке бота означает, что `getMe` не подтвердил
отключение режима; проверяйте права и живую доставку, а не делайте вывод только
по предупреждению. См. [бот](telegram-bot.md).

## Выход, пропуск и редактирование

Создание администратора обязательно. После него доступны «Начать настройку», «Восстановить из резервной копии» и «Пропустить настройку». Пропуск открывает главную панель и сохраняется после обновления страницы и повторного входа. Он отмечает только `setup_dismissed`, а не `setup_complete`: MAX и Telegram остаются не настроенными, мост ожидает необходимых компонентов.

Нажмите блок SHMAX (включая значок и подпись) или «На главную» в мастере. «Отмена / Назад» также позволяет выйти из мастера. Несохранённые изменения требуют подтверждения; выход не сохраняет введённые значения, не отменяет MAX-авторизацию и не удаляет конфигурацию.

Настраивайте компоненты отдельно: MAX → «Настройки MAX» (`/max/settings`); Telegram → «Настройки сети», «Настройки бота», «Настройки группы». Эти страницы используют реальные существующие средства настройки без девяти шагов мастера. Авторизация MAX и «Проверить и сохранить» бота записывают результат явно; кнопка сохранения/возврата или отмены возвращает в раздел компонента. Пустой токен не заменяет сохранённый. На главной выберите «Продолжить первоначальную настройку», чтобы вернуться к шагу MAX, а не создавать администратора заново.

Истёкшая сессия MAX, неверный токен Telegram и недоступная сеть показываются в соответствующем разделе и не запускают мастер автоматически. Все разделы по-прежнему требуют входа администратора.
