# Telegram бот

1. Откройте @BotFather, отправьте `/newbot`, задайте имя.
2. Username должен заканчиваться на `bot`.
3. Скопируйте token в SHMAX. Токен хранится зашифрованно; API возвращает маску.
4. В BotFather выполните `/setprivacy`, выберите бота → **Disable Privacy Mode**
   для получения обычных сообщений группы. Проверьте также права администратора
   в [группе-форуме](telegram-group.md).
5. Сохраните и проверьте бота через выбранную сеть Telegram.

Проверка `getMe` подтверждает доступность API и личность бота, но не доставку
сообщений конкретной группы. Поле `can_read_all_group_messages`, если оно вернулось,
сообщает об отключённом Privacy Mode. Если `getMe` этого не подтвердил, SHMAX
покажет предупреждение. Оно не доказывает, что бот не получает сообщения:
проверьте права администратора, настройку BotFather и живое сообщение в General.

Проверка токена не запускает постоянный слушатель. Он запускается при получении
кода подключения группы; код выдаётся только при живом слушателе. Повторные
запросы не создают второй цикл получения обновлений.

[Синхронизация участников](telegram-group.md#автоматическое-обнаружение-участников)
необязательна, требует отдельные API ID/API Hash и использует того же бота.
Она не требует человеческого Telegram-аккаунта и не выдаёт пользователям доступ.
