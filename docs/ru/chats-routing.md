# Чаты и маршруты: MAX чат ↔ Telegram тема

- На шаге «MAX чаты» выберите чаты MAX — каждый получит свою тему
  в форум-группе.
- Маршруты хранятся в БД (max_chat_id ↔ telegram_chat_id +
  thread_id), их можно включать/выключать и пересоздавать тему.
- Ответы: reply в теме уходит в исходный чат MAX; reply в MAX
  уходит в тему. Маппинг идентификаторов — в таблице
  `message_map`, каждое исходящее нативное сообщение регистрируется
  для защиты от эха (без видимых маркеров).
- Неизвестная тема форум-группы — fail-closed: сообщение не
  бриджуется.
