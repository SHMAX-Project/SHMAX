# Отдельная сеть MAX (v0.2.0)

В мастере настройте сеть MAX **до ввода телефона**. После установки откройте
**MAX → Сеть MAX и Xray**. Telegram имеет собственную страницу сети: выбор
узла для MAX не меняет его подключение.

1. Оставьте **Напрямую**, если сервер может подключаться к MAX.
2. При необходимости выберите **HTTP CONNECT**, **SOCKS5** либо **Xray**.
   Для Xray загрузите свою подписку, выберите поддерживаемый узел и примените его.
   Доступность MAX зависит от выбранного узла; географическое название не является гарантией.
3. Для обычного прокси сохраните хост, порт и, если нужны, логин и пароль.
4. Нажмите **Проверить сохранённое подключение**. Проверяется TCP/TLS-соединение
   с MAX, без авторизации, SMS и отправки сообщений. Затем переходите ко входу.

Новый узел Xray применяется после сетевой проверки. Если проверка не проходит,
восстанавливается предыдущий выбранный узел. Автоматического обхода через
прямое подключение нет. При смене рабочей сети восстанавливается существующая
сессия; если её отозвал MAX, потребуется обычный вход владельца.

Для MAX используются отдельные зашифрованные настройки и отдельный процесс
Xray. Локальные порты по умолчанию: SOCKS `127.0.0.1:10809`, HTTP CONNECT
`127.0.0.1:10810`; Telegram продолжает использовать `127.0.0.1:10808`.
Их не нужно публиковать из Docker. При переопределении переменных
`SHMAX_MAX_XRAY_SOCKS_PORT`, `SHMAX_MAX_XRAY_HTTP_PORT` и
`SHMAX_XRAY_SOCKS_PORT` укажите разные порты.

SOCKS5 для MAX также требует установленный Xray: локальный HTTP CONNECT
вход передаёт трафик выбранному SOCKS5-прокси. Это позволяет направить одним
путём не только TCP-сессию, но и загрузку фото/файлов SDK и скачивание вложений.
URL подписки и пароль прокси не возвращаются в интерфейс; пустой пароль
сохраняет прежний только для того же хоста, порта, логина и режима.
