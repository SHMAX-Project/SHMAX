# FAQ

**Можно ли использовать бота MAX вместо аккаунта?** Нет, V1 —
обычный аккаунт MAX.

**Где мои данные?** `/var/lib/shmax`. Сохраняется при обновлении и пересоздании контейнера;
от удаления данных и поломки диска защищают резервные копии.

**Нужен ли интернет при загрузке сервера?** Нет: boot ждёт только
локальный адрес, веб-интерфейс может запуститься без интернета. Доставка
сообщений требует доступа к MAX и Telegram; GitHub нужен для проверки/скачивания обновлений.

**Можно ли поставить на общий IP?** Да, порт/адрес настраиваются
в `compose.yaml` и `.env`. Compose по умолчанию использует loopback;
инсталлятор может сохранить LAN-адрес — проверьте своё окружение.

**Обновления автоматические?** Проверка — да; установка — только
вручную.

**Что если MAX забанит аккаунт?** Используйте аккаунт согласно
правилам MAX; SHMAX не обходит ограничения.


## Синхронизация участников

Чтобы импортировать существующих молчавших участников, на странице Telegram
сохраните необязательные API ID и API Hash из my.telegram.org. API Hash — секрет.
Используется существующий бот, без человеческого userbot. На странице
«Пользователи» нажмите «Синхронизировать с Telegram» и проверьте результат.
Им не нужно писать боту при настроенной полной синхронизации. Будущие изменения
членства приходят через chat_member; видимые сообщения остаются запасным способом.
Без настроек и при ошибке синхронизации мост продолжает работать.

Новые участники не одобрены и имеют роль read_only; Telegram admin не даёт
SHMAX admin. Существующие ACL и ник сохраняются. Подробнее:
[Telegram-группа](telegram-group.md#автоматическое-обнаружение-участников).
