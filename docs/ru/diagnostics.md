# Диагностика и health

- `/health/live` — жив ли процесс. `/health/ready` — готов ли
  обслуживать (используется инсталлятором, boot-оркестрацией и
  апдейтером). ВАЖНО: это проверка ВНУТРИ контейнера; для хоста
  boot-оркестрация дополнительно проверяет публикацию порта.
- Страница «Диагностика»: состояние MAX/Telegram (HEALTHY /
  DEGRADED / DOWN / AUTH_REQUIRED / RECONNECTING / VERIFICATION_UNAVAILABLE), данные загружаются при открытии страницы. Для новой проверки обновите страницу;
  проверка соединения Telegram доступна в его разделе настроек.
- MAX recovery и Telegram recovery владеют восстановлением своих соединений; watchdog-снимки хранятся в `state/watchdogs.json`. Временная невозможность проверки не доказывает отзыв сессии. Подробности: [MAX](max.md), [журнал](event-journal.md).
- `shmax doctor` — CLI-диагностика (очередь, секреты, сессии).
