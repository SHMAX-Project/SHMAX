# Xray: подписка, ноды, VLESS/Trojan

## Как это работает

1. URL подписки сохраняется в SecretStore (зашифрованно).
2. Тело подписки (≤ 2 МиБ) скачивается и парсится: VLESS/Trojan,
   транспорты tcp/ws/grpc, TLS/Reality (Vision — только на TCP).
3. Нода выбирается вручную; SHMAX:
   - валидирует конфиг **настоящим бинарём Xray** (`run -test`);
   - пишет ephemeral конфиг 0600 в /run-подобный каталог;
   - запускает ровно один процесс Xray;
   - ждёт готовности локального SOCKS (127.0.0.1:<порт>);
   - направляет Telegram-адаптер в этот SOCKS.

## Надёжность

- Выбор ноды сохраняется (кэш): после перезапуска Xray поднимется
  без доступа к серверу подписки.
- Отмена/таймаут/падение любой стадии не оставляет процессов:
  cleanup подтверждает завершение ребёнка (TERM → KILL → reap).
- Живой процесс видно на `/api/telegram/xray/status` (pid, state).

## Ограничения V1

- gRPC + Reality + Vision — не поддерживается (семантическая
  валидация + config-test).
- Xray не обновляется автоматически: бинарёр закреплён
  (v25.3.6, SHA256 в коде установки).
