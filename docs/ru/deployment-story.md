# Первый опыт эксплуатации

SHMAX v0.1.0 был запущен на действующем сервере владельца проекта.
После обновления приложение успешно отвечало на проверку готовности:
база данных, хранилище и runtime были доступны. Владелец подтвердил, что
обновлённая установка работает.

Этот опыт стал поводом сделать путь установки доступнее: добавить установку
одной командой и сохранить ручную установку из архива. Для публичного выпуска
отдельно проверены чистый Debian 13 amd64, обновление с сохранением тестовых данных
и откат после принудительного отказа кандидата.

[Результаты проверки VM](https://github.com/SHMAX-Project/SHMAX/actions/runs/38054225801).

Подтверждение действующей установки не является измерением производительности.
Статистика объёма сообщений, длительная проверка под нагрузкой и отчёты о реальных
проверках всех типов вложений пока не опубликованы.
