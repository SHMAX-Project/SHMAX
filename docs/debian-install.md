# Debian installation

This stable entry point replaces obsolete stage instructions. Current guides:

- [Русский — канонический](ru/installation.md)
- [English](en/installation.md)

Current installer builds the container and configures shmax-hostd and
shmax-boot.service. Use the printed one-time /setup?t=<token> URL only for
unconfigured systems. Never delete /var/lib/shmax to repair or reinstall.
