This stable entry point replaces obsolete stage instructions. Current guides:

- [Русский — канонический](ru/backups.md)

Current UI creates/lists archives. Download, whole-archive passphrase encryption
and restore use CLI/API. A normal .shmax includes the master key and is sensitive.
Stop runtime before CLI restore; API restore coordinates the runtime.
